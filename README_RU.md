# CPU-Maze (3D Рейкастинг на самодельном процессоре)

Это мой второй игровой проект. Это 3D-лабиринт, написанный на Python с использованием библиотеки Kivy.
Главная фишка: поворот камеры рассчитывается на моем самодельном 32-битном процессоре (эмуляция на Python)!

## Как запустить
1. Установите Python 3.
2. Установите библиотеку Kivy:
   pip install kivy
3. Запустите основную игру:
   python main.py
4. Запустите версию с дверями:
   python doorsmain.py

## Управление
*   **ВПЕРЁД** - Идти вперёд.
*   **<** - Повернуть налево.
*   **>** - Повернуть направо.
*   **USE** - Взаимодействовать с дверями (в doorsmain.py)

## Особенности
*   Движок 3D-рейкастинга (стены рисуются с помощью математики).
*   Мини-карта в правом верхнем углу.
*   Выход (зеленая точка) - дойдите до нее, чтобы победить (в main.py)!

## Альтернативные версии
*   **Режим Дверей (`doorsmain.py`):** Хоррор-версия игры. Она включает в себя симметричные комнаты, соединенные дверями. Вы можете открывать и закрывать двери с помощью кнопки **USE**. Также здесь есть мерцающий свет и страшный скример.

## Технические заметки и производительность
*   **Ограничение FPS:** Игра ограничена 20 кадрами в секунду (FPS). Это сделано специально, чтобы как телефоны, так и старые ПК не перегревались и не тормозили. Не пытайтесь увеличить FPS на слабом железе.
*   **Производительность:** Игра использует движок рейкастинга на чистом Python. На слабых устройствах (старые смартфоны, бюджетные ноутбуки) она может подтормаживать. Это нормально.
*   **Если игра вылетает:** Возможно, вашему устройству не хватает мощности процессора для 3D-вычислений. Попробуйте закрыть другие приложения или фоновые процессы.

## Технические детали
Процессор: Написан на Python с нуля. Рассчитывает угол поворота камеры.
Kivy: Отвечает за графику и интерфейс.
